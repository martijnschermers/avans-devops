# Avans DevOps

This project showcases the implementation of a few design patterns. The following patterns are implemented: 
- State pattern
- Composite pattern
- Strategy pattern
- Factory method pattern 
- Template pattern
- Observer pattern

In the project there was also additional focus on writing meaningful tests that validate the quality of the code written. Based on predefined testcases, unit tests were developed. Besides the unit tests a static code analysis took place in the CI/CD pipeline with Sonarcloud. The Sonarcloud implementation provides useful details about the code that is written, like test coverage and possible security vulnerabilities.
